# Verteilte Interpretation – Promptmaterialien

Begleitmaterialien zu Kapitel 12 der Dissertation von Fabio Roman Lieder.

Das Repository dokumentiert Prompts und Module des untersuchten
Konfigurationswegs. Die Materialien werden schrittweise ergänzt.

## Geplanter Aufbau

- 01-naives-prompting
- 02-monolithisches-prompting
- 03-modulares-prompting
- 04-agentisches-prompting

## Fassungen und Verwendung

Jede Datei wird dem zugehörigen Dissertationsabschnitt zugeordnet.
Erhaltene historische Fassungen und spätere Überarbeitungen werden
unterschieden. Nachträgliche Rekonstruktionen werden gekennzeichnet.

Die methodologische Einordnung und die Grenzen der untersuchten
Durchläufe werden in der Dissertation erläutert.

## Forschungsdaten

Empirische Transkripte und vertrauliche Forschungsdaten sind nicht
Bestandteil dieses Repositories. Material, das einem Prompt separat
beigegeben wurde, wird beschrieben, aber nicht automatisch mitveröffentlicht.

## Status

Arbeitsstand. Noch keine abschließend zusammengestellte Dissertationsfassung.
